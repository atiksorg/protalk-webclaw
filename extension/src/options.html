Экспорт / Импорт конфига

Скачайте текущие настройки в JSON-файл или загрузите ранее сохранённый. Auth Token экспортируется для удобства переноса настроек.

Удалённый конфиг (переживает переустановку)

Создай публичный Gist с файлом (например, protalk-claw.json) и вставь сюда raw-URL. Содержимое Gist переживает удаление и переустановку расширения. Пример JSON: {"user_email":"...","model":"openai/gpt-4o","user_context":"..."}. Локальные поля имеют приоритет: если поле уже заполнено в форме, оно не перезаписывается. ⚠️ Никогда не включайте api_key в Gist! Секреты хранятся только локально. 
{
  "user_email": "you@example.com",
  "provider": "openai",
  "api_base_url": "https://openrouter.ai/api/v1",
  "model": "openai/gpt-4o",
  "temperature": 0.2,
  "reasoning": "low",
  "step_cap": 200,
  "user_context": "Имя, контакты, что писать в сопроводительном...",
  "cdp_input_mode": false,
  "spa_network_idle_ms": 500,
  "spa_dom_stable_ms": 300,
  "agent_viewport_width": 1280,
  "agent_viewport_height": 800,
  "token_limit": 1000000
}
⚠️ НЕ включайте api_key в Gist!
Auth Token экспортируется для удобства переноса настроек.
